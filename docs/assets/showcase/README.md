| 文件 | 场景 | 展示目的 |
|---|---|---|
| `01-search-zh-light.png` | 中文亮色搜索页 | 展示统一入口、综合答案、引用和结果列表。 |
| `02-serp-quick-switch.png` | 中文原生 SERP | 展示扩展在结果页内的来源快切。 |

| `04-search-en-dark.png` | 英文暗色搜索页 | 展示国际化与暗色主题下的搜索体验。 |
| `05-agent-bridge-en-dark.png` | 英文暗色 Agent Bridge | 展示本地智能体接入、技能包与配置边界。 |
| `07-selection-search-zh-light.png` | 中文亮色划词搜索 | 展示用户在任意网页选中文本后，就近展开 Juso 搜索来源菜单。 |
